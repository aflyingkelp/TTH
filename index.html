Connect YouTube search

Live search needs your own YouTube Data API key. Pasted links work without one.

  1. Open Google Cloud Console and create or select a project.
  2. In APIs & Services → Library, enable YouTube Data API v3.
  3. In APIs & Services → Credentials, create an API key.
  4. Restrict it to Websites, allowing https://aflyingkelp.github.io/*. Under API restrictions, allow only YouTube Data API v3.
  5. Paste the restricted key below and select Connect. Google applies project quotas; browsing and searching consume them.

The key goes directly to Google when you use search. TTH does not upload it to GitHub or its chat backend. Browser keys are visible to browser users: restrict the key before using it. Without “Remember,” it lasts for this tab only.
